## 项目概述

- **项目名**：chat-lite（曾用名 ember，2026-07-17 迁仓改名）。
- **是什么**：单页聊天网页，可保存多个本地会话、从 OpenRouter 模型目录选择模型并设置系统提示词。
- **仓库**：https://github.com/cloudxuan1/chat-lite （public）
- **访问网址**：https://cloudxuan1.github.io/chat-lite/
- **要密码**：打开后要输访问密码才能用（防陌生人白嫖 API key）。
- **定位**：轻量聊天工具，对话历史存本地浏览器（localStorage），可手动清空。

## 架构

```
浏览器（GitHub Pages 上的 index.html）
   ├─ POST { action:"models", password } → 拉取可选模型
   ├─ POST { action:"title", password, text } → 生成新会话短标题
   │
   │  POST { messages, model, password, reasoningEffort,
   │         session_id, webSearch, maxCompletionTokens? }
   ▼
Cloudflare Worker（ember-proxy）
   │  1. 校验访问密码（对照 Secret ACCESS_PASSWORD），错就 401
   │  2. 模型目录请求：带 Secret 拉 OpenRouter models 并精简返回
   │  3. 标题请求：带 Secret 调 DeepSeek V4 Flash，关闭 thinking
   │  4. Claude 聊天请求：为 system、历史尾部、当前问题加缓存断点
   │  5. 加 Authorization，转发推理档位、生成上限和会话级 session_id，开 stream:true
   ├────► DeepSeek（只返回自然会话标题）
   ▼
OpenRouter（/api/v1/chat/completions）
   ▼
网页中选定的模型（默认 anthropic/claude-opus-4.6）
   │  SSE 流式返回
   ▼ 原样透传回浏览器，前端逐字渲染（打字机效果）
```

- **为什么要 Worker 当中间人**：API key 不能放前端（会被偷）。Worker 在服务端偷偷加 key，前端永远看不到。
- **密码门禁的必要性**：CORS 只防浏览器跨站，挡不住 curl 直连 Worker。所以加一道密码校验，没对密码一律 401，绝不调用 OpenRouter 或 DeepSeek。
- **为什么每会话独立 `session_id`**：OpenRouter 会用它辅助 sticky routing。不同本地会话复用同一个值，容易把无关主题黏到同一供应商会话；独立值既保留同一会话的缓存连续性，也隔开不同主题。

## 技术栈和配置

- **前端**：原生 HTML/CSS/JS 单文件（index.html），无框架、无依赖。
- **代理**：Cloudflare Worker（Module 格式，worker/worker.js）。
- **模型**：通过 Worker 自动拉取 OpenRouter 模型目录；默认 `anthropic/claude-opus-4.6`（注意是点不是横杠），前端没有手填模型 ID 入口。
- **自动标题**：Worker 使用 `deepseek-v4-flash`，关闭 thinking、最多等待 8 秒；只发送首条消息前 500 个 Unicode 字符。中文通常生成 8–18 字，英文可更长，必要空格和标点保留；前端与 Worker 只用 48 字符作安全上限。失败时前端静默保留本地标题。
- **wrangler.toml**：name=`ember-proxy`，main=`worker.js`，compatibility_date=`2024-11-01`。
- **前端顶部可配置常量**（index.html）：
  - `WORKER_URL = "https://ember-proxy.claude-bflwhp.workers.dev"`
  - `DEFAULT_MODEL = "anthropic/claude-opus-4.6"`
- **Worker 顶部常量**（worker.js）：
  - `ALLOWED_ORIGIN = "https://cloudxuan1.github.io"`（CORS 放行来源，必须等于 Pages 域名）
  - `DEFAULT_MODEL = "anthropic/claude-opus-4.6"`

## 设计系统

取自 DESIGN_副本.md 的「怀旧版（Claude Theme）」，前端只用了这一套：

| Token | 值 |
|-------|-----|
| 页面背景 | `#faf9f5`（米白）|
| 卡片背景 | `#ffffff` |
| 主文字 | `#141413` |
| 辅助文字 | `#9b9b97` |
| 强调色（暖棕）| `#d97757`（用户气泡、spark 圆点）|
| 主按钮 | `#3b3b3b` |
| 阴影 | `0 3px 15px rgba(0,0,0,0.05), 0 0 0 0.5px rgba(31,30,29,0.12)` |
| 卡片圆角 / 小圆角 | `20px` / `8px` |
| 标题字体 | `'Anthropic Serif', Georgia, serif` |
| 正文字体 | `-apple-system` 系统无衬线 |

- **字号偏离设计稿**：设计稿正文 12px，聊天界面放大到正文 15px、输入框 16px。原因：聊天要读长文 + iOS 输入框 <16px 聚焦会自动放大页面。
- **布局**：手机优先，单列。顶栏左侧品牌、正中模型简称、右侧清空和设置；消息流与底部输入栏保持原结构。设置使用覆盖全屏的独立界面。
- **多会话导航**：点左上角 `ember` 打开会话列表。手机使用不超过 320px 的抽屉，桌面使用 288px 侧栏并让聊天区自然让位；视觉尺寸紧凑，但按钮和会话行保留至少 44px 触控高度。手机抽屉外的点击层保持透明并关闭 iOS tap highlight，背景层次只用聊天区透明度表达，根页面始终保留奶白底色；不要再在抽屉下铺带颜色的全屏 fixed 遮罩。`theme-color` 仅作浏览器兼容提示，不承担抽屉变暗效果。
- **标题长度纪律**：标题按真实内容与语言决定长短，不用同一个十字限制硬切中文和英文；正常空格、逗号、句号和连字符属于内容，必须保留。数据层只设宽松安全上限，显示层用单行省略处理空间不足。
- **设置交互**：模型简称打开轻量快捷层，可直接切推理程度和联网；右上细线齿轮进入完整设置。模型选择和系统提示词各有独立全屏页：模型页显示完整目录、搜索、即时星标收藏和居中返回顶部按钮；提示词编辑区随内容自动长高。模型、提示词、推理档位和最大生成量最后由「保存并返回」统一落盘，所有主要触控目标不小于 44px。
- **最大生成量**：默认留空，不向 OpenRouter 发送额外限制；可手填任意正整数，上下按钮或键盘方向键每次增减 1024。所填值包含内部思考，超过模型目录提供的 `max_completion_tokens` 时阻止保存。
- **动效**：快捷层淡入并轻微位移；设置页从右侧进入；手机会话抽屉与聊天区明暗使用同一段 240ms 时序，只改变 `transform` / `opacity`，且可被新操作打断。`prefers-reduced-motion` 下取消位移动效和顺滑滚动。玻璃材质只用于模型页返回顶部按钮，`prefers-reduced-transparency` 下回退为实色。
- **密码界面**：复用怀旧版卡片样式（白卡+轻阴影+serif 的 ember），全屏遮罩居中。

## 数据库

无。所有本地状态都在当前浏览器的 localStorage：

- `ember_pw`：访问密码
- `ember_conversations_v1`：当前会话 ID + 多个会话；每个会话包含短标题、用户/助手正文、独立 `sessionId` 和创建/更新时间
- `ember_conversations_v1_corrupt_backup`：发现结构损坏时保留的原始索引，只在恢复场景出现
- `ember_messages`、`ember_session_id`：旧版历史与 session；首次迁移后仍保留，不主动删除
- `ember_model`、`ember_model_favorites`、`ember_model_catalog`：当前模型、收藏和离线模型目录
- `ember_system_prompt`、`ember_reasoning_effort`、`ember_max_completion_tokens`、`ember_web`：系统提示词、推理档位、可选最大生成量和联网开关
- `ember_sidebar_desktop_open`：电脑侧栏展开偏好
