# 前端文件夹回归检查

在仓库根目录使用 Node.js 22 或以上，无需安装依赖：

```sh
node --test tests/*.test.mjs
node worker/cache.test.mjs
git diff --check
```

功能测试通过 `source.mjs` 按 `index.html` 的 script 顺序读取真实生产函数和监听器，在隔离的 VM 中执行，不复制业务实现。提取不到唯一函数会直接失败，拼接源码也会做语法检查。

`script-loading.test.mjs` 新增 2 项无依赖检查：空存储 / 有旧提示词的情况下，按 HTML 顺序逐个执行经典脚本，在文件间触发选区事件并运行其定时器，确保不会读到尚未初始化的状态；同时检查顶层 `let` 只在 store、各文件独立语法有效。DOM 是替身，不执行 `init.js` 的首屏渲染，不等于浏览器验收。`CHAT_LITE_TEST_REF=d8026b0 node --test tests/script-loading.test.mjs` 可复现原 PR #18 的两项 `pending is not defined` 失败。

`folder-order.test.mjs` 另提取生产文件夹渲染、存档归一化/保存和拖动监听器，新增 9 项检查：组内上下排序、拖回原位不写入、保存失败立即回滚与重试、落位中再次拖动（含第一次保存失败）、拒绝旧 DOM、减少动态效果时立即保存。测试 DOM 保留节点身份和移除/插入行为；布局、指针捕获和事件为替身，不等于浏览器触摸验收。

## 覆盖与边界

- 移动到置顶/未置顶/原文件夹、移出、新建后移动：保存成功才关闭菜单并重绘，焦点目标正确。
- 菜单互斥、再次点击「…」关闭、Esc、`aria-expanded`。
- 存储失败不更改原分类，保留菜单并可重试；新建文件夹与移动的两次保存分别注入失败。
- 回复进行中禁止移动，无效目标不误移出；新会话继承分类、空白会话复用及保存失败。
- 老存档原样加载、无效引用回到未分类、删除文件夹不删对话、改名/置顶不改变会话。
- 移动/删除/导入保持消息、`sessionId`、图片附件元数据和 reroll 版本。
- 恢复新会话带上分类；同 id 会话/文件夹不覆盖，尤其不把用户主动移出的会话重新归类；重复导入幂等，老格式兼容。

DOM、整页渲染、焦点、弹窗和 localStorage 都是测试替身。图片 Blob/IndexedDB、下载上传、移动端布局、实际浏览器事件传播、流式聊天和提示词库合并不在这套测试范围内。没有真实模型网络请求，也没有新增前端 CI 工作流；本地通过不能等同于浏览器验收或 GitHub CI 通过。

## 合并前浏览器验收（尚待完成）

使用功能分支页面、独立测试数据，不要清除真实聊天数据。桌面与 iPhone 各走一遍：

1. 建两个置顶文件夹 A/B 和一个未置顶文件夹 C。把测试会话从 A 移到 B、同 B 再选一次、移出：菜单应关闭；桌面键盘焦点回到会话「…」。
2. 移入 C 或从菜单新建文件夹后移动：侧栏不残留会话或菜单，焦点到「文件夹」入口；进管理页应能找到会话，刷新后分类仍在。
3. 打开移动选择器，再点自己的「…」、另一会话「…」、文件夹「…」、空白处和 Esc：任一时刻只出现一个菜单。核对详情页进入/返回、手机抽屉与弹窗取消。
4. 在有消息的文件夹会话中新建会话应继承分类；详情页新建可复用空白会话。用测试环境模拟存储写入失败后，不应显示一个刷新就撤回的分类。
5. 测试会话附带图片和多个 reroll 版本，备份后在隔离环境恢复，检查图片实际可见、分类/版本保留；重复导入不重复。已有会话主动移出后导入旧备份，应保持未分类。删除文件夹应只移出成员，不删除会话/图片。
6. 普通发送、编辑、切换 reroll 版本及流式回复期间禁用操作做一次冒烟回归；涉及真实模型请求由验收者自行决定，不属于本地测试。
